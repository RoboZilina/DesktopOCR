DesktopOCR — User Guide

DesktopOCR is optimized for Japanese VN subtitles: capture a region once, let PaddleOCR read each frame, and review translated text, validators, and TTS from a single workflow.

Workflow Overview

  1. Select a window or region. Use the top bar menu button → “Select Window” or supply a custom region.
  2. Capture & recognize. The preview column shows the live feed, OCR boxes, and the current transcription tray.
  3. Review outputs. History sidebar keeps every line. Optional validators (OpenAI, DeepSeek, Google Vision) can refine text.
  4. Translate & voice. Trigger translation/TTS from tray buttons or automatically via the side menu toggles.

Top Bar Controls

Engine Switch between Paddle variants (pre-tuned for VNs), Windows OCR, or EasyOCR fallback.
Menu Opens the slide-in settings menu described below.
Select Window Pick any visible HWND. The app crops to the VN textbox band once per capture session.
Stop Releases the capture loop and validators; use this before closing or switching windows.

Side Menu Sections

Theme

  • Auto tracks the OS theme (recommended).
  • Dark / Light force a palette for all widgets.

Capture & Display Toggles

  • Auto-Capture, Auto-Copy, Auto-Read Selection
  • History Panel / Capture Preview visibility
  • VN Text Cleaner (validator assists)

Translation

  • Enable translation & auto-translate selection.
  • Backend choice: Auto (DeepL primary, Google fallback) or BYO Google/Libre.
  • LibreTranslate URL field appears when backend=“libre”.

AI Validators

  • OpenAI: toggle, API key, model, usage counters.
  • DeepSeek: toggle, budget-mode helper, API key + model.
  • Google Vision: toggle + API key entry.

Typography & Tray Size

  • Text Size presets (S/M/L) change the transcription tray font.
  • Text Area Size adjusts the tray height for long sentences.

Advanced

  • Diff Threshold slider (frame-change detection before recapture).
  • Reset to Defaults — restores every toggle and threshold.
  • User Guide — opens this document.

Highlighting Explained

Dictionary Underlines

Shows how common each word is in everyday Japanese.

  • Solid underline — very common word
  • Dotted underline — less common word
  • No underline — rare or unknown

Inflected forms automatically inherit the base dictionary lemma (e.g., 行かない → 行く).

Kanji Backgrounds

Highlights individual kanji by category.

  • Jōyō kanji — taught in school, widely used
  • Jinmeiyō kanji — used mainly in names

This layer is visual only and does not affect word frequency.

Combined Layers. Both passes can be enabled independently. When both are active, underlines show word frequency and background tints show kanji category. They never overwrite each other.

Widgets & Panels

  • Preview Widget: Live frame with OCR boxes, capture guides, and status overlays.
  • OCR Canvas: Displays the current Paddle crop and recognition output.
  • Transcription Tray: Shows the latest recognized line, translation, validator hints, copy/recapture controls, and TTS buttons.
  • History Sidebar: Scrollable log of prior lines with quick actions (translate, TTS, copy).

Keyboard & Tips

  • Ctrl+C copies the current tray text when Auto-Copy is disabled.
  • Esc closes dialogs (User Guide, selection overlays, etc.).
  • Use settings.json for persistent defaults; the side menu updates this file automatically.
