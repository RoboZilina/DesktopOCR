DesktopOCR — User Guide

DesktopOCR is optimized for Japanese VN subtitles: capture a region once, let PaddleOCR read each frame, and review translated text, validators, and TTS from a single workflow.

Workflow Overview

  1. Select a window or region. Use the top bar menu button → “Select Window” or supply a custom region.
  2. Capture & recognize. The preview column shows the live feed, OCR boxes, and the current transcription tray.
  3. Review outputs. History sidebar keeps every line. Optional validators (OpenAI, DeepSeek, Google Vision) can refine text.
  4. Translate & voice. Trigger translation/TTS from tray buttons or automatically via the side menu toggles.

Top Bar Controls

Engine Switch between Paddle variants (pre-tuned for VNs) or Windows OCR.
Menu Opens the slide-in settings menu described below.
Select Window Pick any visible HWND. The app crops to the VN textbox band once per capture session.
Stop Releases the capture loop and validators; use this before closing or switching windows.

Side Menu Sections

Theme

  • Auto tracks the OS theme (recommended).
  • Dark / Light force a palette for all widgets.

Capture & Display Toggles

  • Auto-Capture, Auto-Copy, Auto-Read Selection
  • History Panel / Capture Preview visibility
  • VN Text Cleaner (validator assists)

Translation

  • Enable translation & auto-translate selection.
  • Backend choice: Auto (DeepL primary, Google fallback) or BYO Google/Libre.
  • LibreTranslate URL field appears when backend=“libre”.

AI Validators

  • OpenAI: toggle, API key, model, usage counters.
  • DeepSeek: toggle, budget-mode helper, API key + model.
  • Google Vision: toggle + API key entry.

Typography & Tray Size

  • Text Size presets (S/M/L) change the transcription tray font.
  • Text Area Size adjusts the tray height for long sentences.

Advanced

  • Diff Threshold slider (frame-change detection before recapture).
  • Reset to Defaults — restores every toggle and threshold.
  • User Guide — opens this document.

Highlighting Explained

Dictionary Underlines

Shows how common each word is in everyday Japanese.

  • Solid underline — very common word
  • Dotted underline — less common word
  • Red wave underline — rare word
  • No underline — not in dictionary / unknown

Inflected forms automatically inherit the base dictionary lemma (e.g., 行かない → 行く).

Kanji Backgrounds

Highlights individual kanji by category.

  • Jōyō kanji — taught in school, widely used
  • Jinmeiyō kanji — used mainly in names

This layer is visual only and does not affect word frequency.

Combined Layers. Both passes can be enabled independently. When both are active, underlines show word frequency and background tints show kanji category. They never overwrite each other.

Widgets & Panels

  • Preview Widget: Live frame with OCR boxes, capture guides, and status overlays.
  • OCR Canvas: Displays the current Paddle crop and recognition output.
  • Transcription Tray: Shows the latest recognized line, translation, validator hints, copy/recapture controls, and TTS buttons.
  • History Sidebar: Scrollable log of prior lines with quick actions (translate, TTS, copy).

Anki Integration

DesktopOCR can save OCR results directly to Anki flashcards via the AnkiConnect add-on. Each card captures the full pipeline: recognized text, translation, screenshot, and optional TTS audio.

Prerequisites

  1. Anki must be installed and running.
  2. Install the AnkiConnect add-on: Tools → Add-ons → Get Add-ons → enter code 2055492159 → restart Anki.

Quick Start

  1. Open the side menu → expand Anki Integration.
  2. Toggle Enable Anki on.
  3. Click Test Connection to verify AnkiConnect is reachable. The app also polls every 30 seconds automatically.
  4. Capture some text, optionally select a passage, trigger translation, then click 🃏 to save the card.

Side Menu Settings

Host / Port

Defaults to localhost:8765. Only change if you configured a custom port in AnkiConnect's own settings.

Deck Name

The target Anki deck. Created automatically if it doesn't exist. Default: DesktopOCR.

Tags

Comma-separated tags attached to every card. Default: japanese, vn.

Front Template

Controls what shows on the card front: screenshot, selection text, or both.

Back Template

Controls what shows on the card back: full context, selection only, or OCR text only.

Audio Side

Which card side gets TTS audio playback: front, back, or both.

Auto-translate

When on, translations are fetched silently in the background when you click 🃏. Translation is always fetched fresh from the API for the Anki card.

Card Structure

Each Anki note uses the auto-created DesktopOCR note type with 7 fields:

  • Front — rendered HTML with screenshot/text based on your template choice
  • Back — rendered HTML with context/translation based on your template choice
  • TargetText — selected text (or full OCR text if nothing selected)
  • TargetTranslation — translation of the target text
  • ContextText — full OCR output (surrounding context)
  • ContextTranslation — translation of the context text
  • Screenshot — full-window screenshot as an HTML tag referencing the file stored in Anki's media collection

Audio (if available) is attached as a separate media file linked from the card side chosen in settings.

⚠ Anki must be running for AnkiConnect to respond. The 🃏 button is always clickable when visible; if AnkiConnect is unreachable a dialog explains the issue.

Keyboard & Tips

  • Ctrl+C copies the current tray text when Auto-Copy is disabled.
  • Esc closes dialogs (User Guide, selection overlays, etc.).
  • Use settings.json for persistent defaults; the side menu updates this file automatically.

Troubleshooting

  • Blank translation: Verify the translation backend is enabled in the side menu and the API key (if required) is set.
  • No OCR output: Confirm a source window is selected and the capture region covers the text area.
  • Anki connection fails: Ensure Anki is running and the AnkiConnect add-on is installed.
  • User guide not found: In PyInstaller builds the guide is bundled inside the executable. Reinstall the application if it fails to open.

Bundled Resource

This user guide is bundled into PyInstaller builds of DesktopOCR. The file docs/user_guide.html is copied into the executable via --add-data during the build process. If the guide does not open from within the application, verify that your installation includes this file.
